2. Title of the Experiment

Live character counter in a textarea

Dynamic product filter with dropdown sorting

Interactive SVG drawing tool with mouse events

3. Approach

Word Counter: Used a textarea and JavaScript input event to update character count in real time, with visual feedback for limits.

Product Filter: Displayed products as cards and filtered/sorted them dynamically using dropdown selection and JavaScript.

SVG Drawing Tool: Implemented freeform drawing on an SVG canvas using mousedown, mousemove, and mouseup events, with an option to clear drawings.

4. Result

Real-time character counting with visual warnings.

Product list dynamically filtered and sorted based on dropdown selection.

Users can draw on SVG canvas and clear it as needed.
